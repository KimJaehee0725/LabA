# v0.4 Strict-OSS Research Workspace

작성일: 2026-05-09

## 목표

v0.4.0은 v0.3의 검증된 MLflow + Nextcloud/Collabora baseline을 유지하면서, 연구실용 Notion-like workspace MVP를 추가한다. 기본 활성 서비스 집합은 다음과 같다.

```text
core,edge,authentik,gitea,plane,mlflow,nextcloud,grist
```

Grist는 `https://data.lab.snu.ac.kr`에서 제공하고, Authentik OIDC로 로그인하며, 구조화 DB와 dashboard 정의의 canonical layer로 쓴다.

## Strict OSS 결정

채택:

- Grist OSS: Apache-2.0, OIDC, REST API, widget/dashboard 기반 view를 제공한다.
- Plane CE: AGPL-3.0, project/work item/view/page/API 기반 작업 관리 축으로 쓴다.
- Nextcloud Collectives/Deck/Calendar: 현재 OIDC 및 group 기반 문서 허브에 그대로 붙인다.

제외 또는 보류:

- NocoDB: Sustainable Use License라 strict OSS 기준에서 제외한다.
- Docmost: OIDC/SSO가 Enterprise 기능이라 canonical wiki에서 제외한다.
- Baserow: Calendar/Kanban/Timeline view가 paid feature라 이번 기준에서 제외한다.

## 책임 분리

| 영역 | Canonical system | 책임 |
|---|---|---|
| 작업/담당자 | Plane | 담당자, due date, project/module/cycle status, board/list/layout view, task activity |
| 문서/wiki | Nextcloud Collectives | lab pages, meeting notes, SOPs, onboarding, experiment notes, page links |
| 구조화 DB/dashboard | Grist | people, teams, projects, resources, papers, datasets, experiments, GitHub references, review queue, overview dashboards |
| 일정 | Nextcloud Calendar | shared team calendars, recurring events |

Grist는 주요 날짜 record를 mirror할 수 있지만, calendar ownership은 Nextcloud Calendar에 둔다.

## Seed Data

`deploy/data-model/lab-domain.v0.4.yaml`은 v0.4 non-secret catalog다. 포함 범위:

- domain objects: `People`, `Teams`, `Projects`, `Pages`, `Tasks`, `Resources`, `Papers`, `Datasets`, `Experiments`, `GitHubRefs`, `Events`
- Plane demo issues: assignee, status, due date, labels, Collectives/Grist/GitHub references
- Nextcloud templates: lab home, team pages, meeting notes, literature notes, experiment logs, SOPs, onboarding
- Grist `Lab Research Hub`: required tables plus `DashboardPages` rows for dashboard/card/calendar-style entry points

명령:

```bash
sudo LAB_DOMAIN_CATALOG_VERSION=v0.4 /srv/lab-platform/scripts/52-seed-demo-data.sh
sudo LAB_DOMAIN_CATALOG_VERSION=v0.4 /srv/lab-platform/scripts/73-seed-nextcloud-document-hub.sh
sudo /srv/lab-platform/scripts/75-seed-grist-research-hub.sh
```

Nextcloud Tables는 설치 상태를 유지하지만 v0.4의 Notion-database canonical status는 Grist로 이동한다.

## GitHub 정책

Nextcloud `integration_github`는 dashboard/search/link preview 용도로 유지한다. GitHub PAT/OAuth는 각 사용자의 Connected accounts에서만 설정한다.

금지:

- GitHub PAT를 server env에 저장
- PAT를 report, history, seed data에 기록
- Plane Commercial GitHub integration에 v0.4 core workflow를 의존

v0.4에서는 Plane/Grist/Collectives에 명시적인 GitHub URL/reference field를 둔다.

Static:

```bash

docker compose \
  --env-file deploy/env/00-global.env.example \
  --env-file deploy/env/10-core.env.example \

  -f deploy/compose/grist/docker-compose.yml config
```

Runtime:

```bash
sudo AUTHENTIK_CHECK_DISCOVERY_SLUGS=gitea,plane,nextcloud,grist /srv/lab-platform/scripts/20-check-authentik.sh
```

Expected:

- Grist `/status` returns healthy internally and externally.
- unauthenticated Grist root redirects or denies.
- Authentik discovery works for `grist`.
- `Lab Research Hub` exists with required tables and seed records.
- `DashboardPages` includes `Dashboard`, `Card`, and `Calendar`.
- Postgres backup includes `grist`; Grist persist docs are included in file backup dry-run.

## Versioning

- `v0.3.x`: validated MLflow/Nextcloud/Collabora baseline bugfix only.
