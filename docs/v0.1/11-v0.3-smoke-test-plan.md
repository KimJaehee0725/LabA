# 11. v0.3 Smoke Test Plan

## 목표

v0.3 smoke test는 “운영 준비 완료”가 아니라 “1차 통합 작업물이 실제로 연결되어 동작한다”를 확인하는 단계다.

## 사전 조건

- split env 실제 값 준비
- placeholder domain 또는 `/etc/hosts` 준비
- TLS 방식 준비
- core, edge, authentik, services compose up
- test user: `smoke.member`
- admin user: `smoke.admin`
- test files 준비

## Smoke user

| User | Group | 용도 |
|---|---|---|
| `smoke.admin` | `lab-admin` | admin 기능 |
| `smoke.member` | `lab-member` | 일반 사용자 flow |
| `smoke.collab` | `lab-collab` | 제한 접근 후속 |

실제 password/token은 기록하지 않는다.

## 1. Network and ports

검증:

```bash
docker network ls | grep lab_
ss -tulpn
```

통과:

- `80`, `443`, 필요 시 `2222`만 외부 listen
- Postgres/Redis/MinIO internal port가 host에 없음

## 2. Core

검증:

- Postgres `pg_isready`
- Redis `PING`
- MinIO bucket list
- DB list

통과:

- 서비스별 DB 존재
- bucket 3개 이상 존재: `plane-uploads`, `gitea-lfs`, `mlflow-artifacts`

## 3. Nginx

검증:

```bash
nginx -t
curl -kI https://auth.lab.snu.ac.kr
curl -kI https://hub.lab.snu.ac.kr
curl -kI https://files.lab.snu.ac.kr/status.php
curl -k https://office.lab.snu.ac.kr/hosting/discovery
```

통과:

- HTTP -> HTTPS redirect
- 각 route가 expected status 반환
- Collabora discovery XML 반환

## 4. Authentik

검증:

- admin login
- test user 생성
- MFA enrollment
- OIDC provider 목록 확인
- disabled user login 차단

통과:

- `lab-admin`, `lab-member`, `lab-collab`, `lab-guest` 존재
- `smoke.member`가 MFA 설정 완료

## 5. Gitea

검증:

1. Authentik OIDC login
2. repo 생성
3. SSH key 등록
4. `git push`
5. Git LFS push
6. MinIO `gitea-lfs` object 확인

통과:

- registration disabled
- repo push 성공
- LFS object가 MinIO에 존재

## 6. Plane

검증:

1. Authentik OIDC login
2. workspace 접근
3. project 생성
4. work item 생성
5. page/wiki 생성
6. file attachment upload
7. MinIO `plane-uploads` 확인

통과:

- API/worker/beat 오류 없음
- attachment 다운로드 가능

## 7. MLflow

검증:

1. 인증 전 접근이 Authentik으로 redirect
2. 인증 후 UI 접근
3. smoke experiment 생성
4. metric/param log
5. artifact upload
6. MinIO `mlflow-artifacts` 확인

통과:

- artifact가 local filesystem이 아니라 MinIO에 저장됨
- run metadata가 Postgres에 저장됨

## 8. Nextcloud + Collabora

검증:

1. Authentik OIDC login
2. file upload/download
3. group folder 접근
4. Calendar 접근
5. docx 생성
6. Collabora에서 편집 후 저장
7. WebDAV app password 생성

통과:

- `status.php` 정상
- background jobs가 Cron
- Collabora 편집 저장됨

## 9. Overleaf

검증:

1. admin activation
2. user invite
3. sample project 생성
4. LaTeX compile
5. Korean sample compile
6. project Git clone
7. Gitea remote push

통과:

- compile 성공
- project backup path 작동

## 10. Backup dry-run

검증:

- `backup-all.sh --dry-run`
- Postgres dump 1개 이상 생성
- Gitea dump 생성
- MinIO mirror command dry-run
- Nextcloud maintenance backup dry-run
- Overleaf mongodump dry-run

통과:

- manifest 생성
- 실패 항목이 명확히 보고됨

## 11. Security checks

검증:

- `/srv/lab-platform/env/*.env` 권한 제한
- cert key 권한 제한
- Docker socket mount 없음 또는 승인된 예외만 있음
- anonymous MinIO access 없음
- Gitea registration disabled
- MLflow unauthenticated access blocked
- disabled Authentik user cannot login

## 실패 기준

아래는 v0.3 smoke blocker다.

- Authentik login 불가
- Nginx route 대부분 실패
- Postgres/Redis/MinIO 외부 노출
- MLflow 인증 없이 접근 가능
- Gitea LFS가 동작하지 않음
- Nextcloud OIDC login 불가
- backup dry-run이 전혀 수행되지 않음
