# 10. v0.2 Implementation Backlog

## Backlog 원칙

각 작업은 작은 PR 또는 commit 단위로 분리한다. 보안과 secret 관련 파일은 반드시 review한다.

## Epic A. Repository Layout

### A1. deploy directory skeleton

산출물:

- `deploy/README.md`
- `deploy/env/README.md`
- `deploy/env/*.env.example`
- `deploy/compose/`
- `deploy/nginx/`
- `deploy/scripts/`
- `deploy/runbooks/`

검증:

- secret placeholder만 포함
- `.gitignore`가 실제 `.env`와 cert key 제외

### A1.1. split env examples

산출물:

- `00-global.env.example`
- `10-core.env.example`
- `20-authentik.env.example`
- `30-gitea.env.example`
- `40-plane.env.example`
- `50-mlflow.env.example`
- `60-nextcloud.env.example`
- `70-overleaf.env.example`
- `80-minio-policies.env.example`
- `90-backup.env.example`

검증:

- 실제 secret 없음
- 변수 중복 최소화
- 각 compose runbook이 필요한 env 파일만 참조

### A2. runbook index

산출물:

- `deploy/runbooks/README.md`

내용:

- 실행 순서
