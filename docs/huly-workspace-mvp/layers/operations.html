운영 자동화는 pilot 완료 조건이다

Huly 전환은 기능 배포만으로 끝나지 않는다. 매일 백업, 월 1회 복구 테스트, 인증서 만료 알림, uptime 알림, 보안 로그 요약, 멤버 온보딩 문서가 있어야 연구실 서비스로 운영할 수 있다.

Backup plan

대상 방식 보관 복구 검증
Authentik DB `pg_dump` gzip daily 30일, weekly 12주 별도 test DB에 restore
Huly data deployed version의 공식 store 기준 dump 또는 snapshot daily 30일, weekly 12주 test workspace boot
MinIO data `mc mirror` or filesystem sync backup disk + optional cold storage sample object checksum
HF metadata DB `pg_dump` gzip daily 30일 list/detail endpoint test
Overleaf projects Toolkit backup, Mongo dump, project tar daily 30일 sample project compile
Nginx and cert metadata tar, encrypted private key backup weekly 12주 `nginx -t` in staging path

Monitoring plan

Uptime checks

  • `auth` live endpoint
  • `huly` application health endpoint or login page availability
  • `s3` MinIO live endpoint
  • `hf` backend `/api/health`
  • `overleaf` status page or login page
  • portal root

Host checks

  • primary HDD capacity warning at 80% and critical at 90%
  • backup disk capacity warning at 80%
  • Docker container restart count
  • Nginx 4xx/5xx ratio
  • certificate expiry warning at 30, 15, and 7 days
  • backup job success and latest restore rehearsal date

Routine checklist

주기 작업 Evidence
Daily 백업 성공 알림 또는 실패 알림 확인, 보안 요약 메일 검토 mail log, backup log
Weekly 서비스 uptime, disk usage, Docker restart count 확인 Uptime Kuma, host report
Monthly 백업 복구 테스트, service patch review, 비활성 계정 점검 restore report, update notes
Quarterly 권한 재검토, public bucket audit, secret rotation 후보 검토 access review note
Annual 학교 SSL 갱신, major upgrade plan, disaster recovery rehearsal certificate record, DR report

Onboarding model

Admin flow

  1. Authentik invitation 생성.
  2. `lab-members` 또는 `lab-guests` 그룹 할당.
  3. Huly workspace invite 확인.
  4. 필요 시 Overleaf 계정 별도 생성.
  5. HF-like UI 접근 권한 smoke.

Member guide

  • 첫 로그인과 2FA 등록.
  • Huly 문서, 채팅, 이슈 사용 기준.
  • 모델/데이터셋 업로드 위치와 공개 범위.
  • Overleaf 계정 사용법.
  • 민감 데이터 공유 금지와 private 기본 정책.

Migration guide

  • Notion export: Markdown and CSV.
  • 핵심 페이지 우선 import.
  • 링크와 첨부 파일 수동 검토.
  • 기존 Slack 병행 기간과 종료 조건 기록.
  • Huly 문서 구조 owner 지정.
