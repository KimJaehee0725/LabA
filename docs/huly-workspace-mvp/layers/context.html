보존된 학습

유지할 원칙

  • secret과 실제 인증서는 repo에 두지 않는다.
  • service별 compose와 runbook, check script를 함께 만든다.
  • 외부 노출은 Nginx 경유 HTTPS로 통일한다.
  • 모든 서비스는 독립 smoke gate와 통합 smoke gate를 가진다.
  • 백업은 구현 후 붙이는 항목이 아니라 service DoD에 포함한다.

버릴 방향

  • Plane을 canonical work/task system으로 고정하지 않는다.
  • Nextcloud Collectives를 page/wiki canonical로 고정하지 않는다.
  • Grist를 기본 structured DB layer로 먼저 올리지 않는다.
  • Gitea를 GitHub 대체제로 다시 구성하지 않는다.
  • 이전 `/srv/lab-platform` compose copy와 data layout을 재사용하지 않는다.

새 기준

Branch `huly/workspace-mvp`에서 계획과 구현을 진행한다.
Runtime root 새 서버 root는 `/opt/lab-stack`로 둔다.
Data root 대용량 객체 데이터는 `/mnt/hdd/minio`에 둔다.
Backup root 백업은 `/mnt/backup/lab`에 30일 daily와 12주 weekly로 보관한다.
Identity Authentik 그룹과 OIDC provider를 모든 서비스의 기준으로 둔다.
