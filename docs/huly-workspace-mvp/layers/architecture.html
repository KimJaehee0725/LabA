Huly를 중심으로 두고 주변 서비스를 얇게 붙인다

Huly가 연구실 collaboration surface를 맡고, Authentik은 identity, MinIO는 object storage, HF-like UI는 모델/데이터셋 catalog, Overleaf CE는 논문 편집을 맡는다. Nginx는 외부 공개면과 TLS 종단을 단일화한다.

Logical topology

School DNS + firewall
  -> Nginx reverse proxy with school SSL
      -> Authentik SSO/OIDC
      -> Huly workspace
      -> MinIO Console and S3 API
      -> HF-like UI frontend/backend
      -> Overleaf CE
      -> Portal and optional status dashboard

Persistent data
  -> /opt/lab-stack service configs and app volumes
  -> /mnt/hdd/minio for object data
  -> /mnt/backup/lab for daily and weekly backups

Trust boundaries

Public edge

  • TCP 80 and 443 only.
  • HTTP to HTTPS redirect.
  • School wildcard certificate.
  • Rate limits for auth and API paths.

Authenticated apps

  • Authentik groups: `lab-admins`, `lab-members`, `lab-guests`.
  • 2FA required for every account.
  • Invitation-only enrollment.
  • Emergency local admin per service.

Storage

  • Private by default.
  • Public bucket is explicit and read-only.
  • Large model upload bypasses app memory through streaming or presigned URLs.
  • Backups are separate from primary HDD.
