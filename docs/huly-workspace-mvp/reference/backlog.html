구현은 gate별로 작게 끊는다

각 ticket은 repo 산출물, server 산출물, 검증 명령 또는 수동 검증 evidence를 남겨야 닫는다. secret, 실제 인증서 private key, token, client secret은 어떤 ticket에서도 commit 대상이 아니다.

Ticket Definition of Done

  • 변경 파일이 scope에 맞고 unrelated v0.3/v0.4 방향을 되살리지 않는다.
  • real secret, private key, token, generated client secret이 repo에 없다.
  • 정적 검증 또는 runtime smoke evidence가 있다.
  • 운영자가 재현할 명령과 rollback/stop 절차가 runbook 또는 ticket에 있다.
  • 다음 ticket이 의존하는 endpoint, domain, env key가 명확하다.
