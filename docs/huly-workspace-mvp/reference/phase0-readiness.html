Phase 1 전에 잠가야 할 준비물

Phase 0의 목적은 실제 배포 작업 전에 외부 승인, 서버 접근, 디스크, 보안 정책, 운영 연락망을 확인하는 것이다. 이 문서는 공개 가능한 체크리스트만 담고, 실제 도메인 값, 인증서 private key, SMTP 비밀번호, 담당자 개인정보는 repo에 기록하지 않는다.

commit discipline: small commits secret policy: server-only Phase 1 gate: all required items pass

Exit summary

Must pass

  • 도메인/DNS/SSL/방화벽/SMTP 진행 상태가 확인되어 있다.
  • 서버에 SSH key-only 접근이 가능하다.
  • Docker와 compose plugin이 동작한다.
  • primary data disk와 backup disk가 mount되어 있다.
  • 운영자 알림 mailbox가 정해져 있다.

May be pending

  • 학교 발급 절차가 진행 중인 항목은 ticket 번호와 예상 완료일이 있으면 pending으로 둔다.
  • 실제 certificate file은 Phase 1 전에만 준비되면 된다.
  • SMTP credential은 값이 아니라 승인 상태만 repo 문서에 남긴다.

Must not happen

  • 실제 private key, password, token, client secret을 commit하지 않는다.
  • 이전 `/srv/lab-platform` runtime을 되살리지 않는다.
  • Phase 0가 끝나기 전에 public service를 임의로 열지 않는다.

Security readiness

Host hardening

  • `ufw` allows only SSH, HTTP, and HTTPS inbound unless explicitly documented.
  • `fail2ban` has sshd jail enabled.
  • `unattended-upgrades` is installed and security updates are configured.
  • Deploy user has necessary Docker access but no broad secret sprawl.

Secret policy

  • Repo files contain examples and placeholders only.
  • Runtime env lives under `/opt/lab-stack` or another server-only restricted path.
  • Certificate private key is never copied into docs or commit history.
  • OIDC client secrets and SMTP credentials are recorded only in private operational storage.
