11. 검증 기준 phase gates and smoke evidence

Home / Reference / Validation

각 phase는 gate를 통과해야 다음으로 넘어간다

검증은 명령 출력, 스크린샷, smoke report, runbook 업데이트 중 하나 이상의 evidence를 남긴다. 실패한 항목은 workaround와 재시도 조건을 함께 기록한다.

Edge Gate

Check Command or action Pass condition
DNS `dig auth.lab.example.ac.kr +short` 서버 public IP 반환
HTTP redirect `curl -I http://auth.lab.example.ac.kr` 301 또는 308 to HTTPS
TLS chain `openssl s_client -connect auth.lab.example.ac.kr:443 -servername auth.lab.example.ac.kr` 학교 인증서 chain valid
Nginx config `nginx -t` or container equivalent syntax ok and test successful
Public ports `ss -lntp` and external port scan 22, 80, 443 외 서비스 port public 노출 없음

Auth Gate

Check Action Pass condition
Admin setup initial setup URL에서 admin 생성 admin login 후 dashboard 접근
2FA 새 사용자로 로그인 TOTP 등록 없이는 완료 불가
Invitation 초대 링크 없이 enrollment 접근, 초대 링크로 enrollment 접근 전자는 차단, 후자는 가입 가능
Email test mail, 가입 알림 trigger 운영자 mailbox에 수신
Group claim OIDC test client로 token claim 확인 `lab-admins`, `lab-members`, `lab-guests` claim 확인
Secret handling `rg -i "client_secret|private key|password|token" deploy docs` tracked 파일에는 실제 값이 없고 placeholders만 존재

Huly Gate

Check Action Pass condition
Login protection private browser에서 Huly URL 접근 OIDC 또는 forward-auth login이 요구됨
Workspace seed channels, projects, sample docs 생성 pilot users가 같은 workspace에서 확인
Docs/wiki Notion export sample import 또는 manual copy heading, link, code block, image가 사용 가능
Task flow issue 생성, assignee, due date, status 변경 calendar 또는 project view에 반영
Gantt/timeline start/end date가 있는 issue 여러 개 생성 timeline/Gantt가 self-hosted에서 렌더링
GitHub sync Huly issue 생성, GitHub issue update, PR merge event 양방향 상태 변화가 기록됨
Pilot usage 2명 이상이 1주일 사용 막힌 점과 채택/보완 decision이 남음

Storage Gate

Check Action Pass condition
Console SSO MinIO console 접근 Authentik login 후 console 접근
S3 API `mc alias`, `mc mb`, `mc cp`, `mc stat` upload/download 성공
Policy member와 guest credential 또는 session으로 접근 비교 private bucket guest 접근 차단
Persistence object upload 후 container restart `/mnt/hdd/minio` object 유지
Backup mirror sample bucket mirror to backup disk checksum 일치

HF Gate

Check Action Pass condition
Health `curl https://hf.lab.example.ac.kr/api/health` 200 and version payload
Login member account로 UI 접근 Authentik OIDC session 생성
List/detail sample model and dataset metadata 생성 list와 detail page에 표시
README render Markdown with code block and LaTeX sample 깨지지 않고 렌더링
File tree MinIO prefix scan 파일명, size, modified time 표시
Download presigned URL 발급 후 파일 다운로드 권한 있는 사용자만 성공, URL 만료 동작

Overleaf Gate

Check Action Pass condition
Access Overleaf URL HTTPS 접속 학교 인증서와 login page 정상
Registration public signup 시도 가입 차단
Compile basic LaTeX project compile PDF 생성
Collaboration 2개 계정 동시 편집 실시간 변경 반영
Templates NeurIPS/ICML/ICLR/ACL/AAAI sample compile 각 template PDF 생성
Backup sample project backup and restore 복구된 project가 compile됨

Ops Gate

Check Action Pass condition
Backup daily backup run all service artifacts present under backup root
Restore 월 1회 기준 restore drill sample service/data restored and verified
Uptime alert test endpoint intentionally down 운영자 이메일 또는 Slack 알림 수신
Certificate alert expiry checker dry-run 30/15/7 day warning path 검증
Security summary daily summary script run fail2ban, login failure, nginx error summary 수신
Onboarding 신규 pilot member 1명 초대 guide만 보고 2FA, Huly, HF UI 접근 성공
