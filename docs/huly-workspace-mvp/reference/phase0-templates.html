신청과 검증 기록을 빠르게 남기기 위한 템플릿

이 페이지의 템플릿은 repo에 남겨도 안전한 형태다. 실제 도메인, IP, 담당자 연락처, 인증서 파일명, SMTP credential, token은 private ticket, password manager, 또는 server-only 기록에만 채운다.

Usage rules

템플릿을 복사해 실제 값으로 채운 파일은 commit하지 않는다. 공개 repo에는 placeholder와 절차만 남기고, 운영 값은 private readiness record로 관리한다.
