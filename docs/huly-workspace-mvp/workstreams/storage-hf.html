MinIO는 데이터의 source of truth, HF-like UI는 연구자가 보는 catalog

대형 모델 weight와 dataset은 MinIO에 저장하고, HF-like UI는 metadata, README, file tree, search, presigned download를 제공한다. MVP는 조회와 다운로드를 먼저 완성하고, 업로드와 HF API 호환은 v1로 확장한다.

Bucket structure

Bucket 내용 Path pattern 기본 정책
`lab-models` 학습된 모델 weight, config, tokenizer, card `{owner}/{model}/{version}/...` members read/write, guests none
`lab-datasets` dataset raw/processed split, metadata, license note `{dataset}/{version}/...` members read/write, guests none by default
`lab-artifacts` 실험 산출물, evaluation reports, checkpoints `{project}/{experiment-id}/...` members read/write
`lab-public` 외부 공유 가능한 공개 자료 `{collection}/{name}/...` public read, admin/member controlled write
`lab-backups` 서비스 백업의 optional object mirror `{service}/{date}/...` admins only

MinIO implementation

Service requirements

  • Data volume mounted at `/mnt/hdd/minio`.
  • Console host and API host are separated.
  • Console uses Authentik OIDC.
  • S3 API uses service/user credentials and bucket policies.
  • Versioning enabled for models and datasets.
  • Backup mirror is tested before pilot opens.

Metadata model

models
  id, owner, name, visibility, summary, tags, base_model, license,
  storage_prefix, created_at, updated_at

model_versions
  id, model_id, version, commit_message, files_json, created_by, created_at

datasets
  id, owner, name, visibility, summary, tags, license,
  storage_prefix, created_at, updated_at

dataset_versions
  id, dataset_id, version, split_info_json, files_json, created_by, created_at
HF-like UI의 metadata DB는 MinIO를 대체하지 않는다. object의 canonical bytes는 MinIO에 있고, metadata DB는 검색과 화면 표시를 위한 index다.

API surface for MVP

Endpoint Method Purpose Auth
`/api/health` GET uptime check public or internal
`/api/models` GET list and search models OIDC session
`/api/models/{owner}/{name}` GET model detail and latest metadata visibility-aware
`/api/models/{owner}/{name}/files` GET file tree from MinIO prefix visibility-aware
`/api/files/presign` POST short-lived download URL visibility-aware
`/api/datasets` GET list and search datasets OIDC session

Security notes

Public model/data sharing must be explicit. Default visibility is private or group-only, and `lab-public` write access is restricted. Do not expose raw MinIO console to guests.
