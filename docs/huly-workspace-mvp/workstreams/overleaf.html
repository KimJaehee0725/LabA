Overleaf CE는 논문 협업 전용 서비스로 작게 시작한다

Overleaf CE는 Huly가 대체하기 어려운 LaTeX 협업 편집과 PDF 컴파일을 맡는다. MVP에서는 OIDC/LDAP SSO를 필수화하지 않고, 동일 이메일 기반 별도 계정을 관리자가 발급하는 방식으로 시작한다.

Initial scope

Included

  • Overleaf Toolkit 기반 배포.
  • 외부 공개는 Nginx HTTPS 뒤로 제한.
  • public registration disabled.
  • admin이 사용자 계정을 직접 생성.
  • TeX Live full 또는 필요한 package set 설치.
  • 주요 학회 템플릿 preload.

Deferred

  • Authentik LDAP outpost integration.
  • Overleaf CE SSO custom patch.
  • Git bridge automation.
  • template marketplace 형태의 UI.
  • multi-instance HA.

Configuration decisions

항목 값 이유
Public URL `https://overleaf.lab.example.ac.kr` 서비스별 서브도메인 일관성
Listen address `127.0.0.1:8090` Nginx 외 직접 public 노출 방지
Registration disabled 외부 공개 환경에서 계정 남발 방지
Account model admin-created local accounts CE SSO 부담을 MVP에서 제거
Templates NeurIPS, ICML, ICLR, ACL/EMNLP, AAAI 연구실 논문 workflow에 즉시 필요
Backup Toolkit backup + Mongo/project file dump 논문 프로젝트 복구 가능성 확보

Implementation order

  1. `/opt/lab-stack/overleaf`에 toolkit을 배치한다.
  2. `OVERLEAF_LISTEN_IP=127.0.0.1`, `OVERLEAF_PORT=8090`, `OVERLEAF_SITE_URL`을 설정한다.
  3. public registration을 끄고 SMTP 발송을 검증한다.
  4. Nginx server block과 WebSocket proxy timeout을 적용한다.
  5. admin 계정과 pilot member 계정 2개를 만든다.
  6. TeX Live package set을 설치하고 템플릿을 preload한다.
  7. 2명 동시 편집, PDF compile, template compile, backup dry-run을 검증한다.

SSO decision

초기에는 별도 계정으로 시작한다. Authentik LDAP outpost와 Overleaf LDAP 연동은 운영 burden이 크므로, pilot 사용자가 실제로 별도 로그인을 문제로 보고할 때 v1 decision으로 올린다.
