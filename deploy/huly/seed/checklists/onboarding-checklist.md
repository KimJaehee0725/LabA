# Pilot Member Onboarding Checklist

This sample checklist verifies that a new pilot member can reach the Huly
workspace and understand the basic workflow without private instructions.

## Before Invite

- [ ] Confirm the member should be part of the Huly pilot.
- [ ] Confirm the approved identity-provider group or invitation path.
- [ ] Confirm no shared password is needed.
- [ ] Confirm the member has the pilot URL from an approved channel.

## First Login

- [ ] Open the Huly URL in a private browser session.
- [ ] Complete the identity-provider login flow.
- [ ] Confirm Huly opens the `LabA Huly Pilot` workspace.
- [ ] Confirm `#general`, `#research`, `#paper`, `#infra`, and `#random` are visible.

## First Workspace Tour

- [ ] Open the `Lab Handbook` page.
- [ ] Open the `Meeting Notes` page.
- [ ] Open the `Experiments` project.
- [ ] Open the `Papers` project.
- [ ] Open the `Infrastructure` project.
- [ ] Open the `Datasets` project.
- [ ] Open the `Onboarding` project.

## First Task

- [ ] Assign the member a sample role-based task.
- [ ] Ask the member to add a comment without personal data.
- [ ] Ask the member to update task status once.
- [ ] Confirm the status change appears in the project view.

## Completion

- [ ] Record any blocker as a Huly issue.
- [ ] Record any documentation gap in the Lab Handbook.
- [ ] Confirm the member knows not to post secrets, credentials, private data, or raw research exports.
