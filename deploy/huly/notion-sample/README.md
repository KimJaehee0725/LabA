# Notion Sample

This directory holds the tracked checklist for the Phase 3 Notion migration
sample. It does not contain a real Notion export.

Use the checklist against a private, local export copy that contains only
approved sample pages. Do not commit exported Notion ZIP files, private Markdown
pages, attachment folders, CSV databases, personal data, credentials, or raw
research content.

The pilot target is small on purpose:

- export up to five approved pages
- scrub before import
- import or manually copy into the Huly Lab Handbook area
- record formatting quality and blockers without attaching private raw exports
