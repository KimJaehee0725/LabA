# Phase 5 HF-like UI MVP Runbook

This runbook deploys a small HF-like catalog UI on top of the Phase 4 MinIO
storage layer. The MVP is intentionally narrow: model/dataset list, detail,
README, file tree, download URL flow, and Phase 5.2 dataset preview including
Parquet. Phase 5.3 adds single-file browser upload through presigned S3 PUT
URLs.

## Scope

- UI: `https://hf.lab.example.ac.kr`
- Runtime root: `/opt/lab-stack`
- App container: `hf-ui`
- Metadata source: `/opt/lab-stack/hf-ui/catalog/seed.catalog.yaml`
- Object source: shared core MinIO buckets from Phase 4
- Included MVP buckets: `lab-models`, `lab-datasets`, `lab-artifacts`, `lab-public`
- Upload v1: single-file direct PUT to existing model/dataset prefixes
- Excluded from MVP: multipart upload, folder upload, resumable upload, full
  HuggingFace Hub API compatibility, public community features

## Server Preparation

1. Copy updated deploy files to `/opt/lab-stack`.
2. Create directories:

```bash
sudo /opt/lab-stack/scripts/00-create-directories.sh
```

3. Create `/opt/lab-stack/env/45-hf-ui.env` from
   `deploy/env/45-hf-ui.env.example`.
4. Generate server-only values:

```bash
openssl rand -hex 32  # HF_UI_SESSION_SECRET
openssl rand -hex 32  # HF_UI_STAGING_BYPASS_TOKEN for staging checks only
openssl rand -hex 24  # HF_UI_S3_ACCESS_KEY
openssl rand -hex 32  # HF_UI_S3_SECRET_KEY
```

5. In `/opt/lab-stack/env/20-authentik.env`, confirm:

```bash
HF_UI_OIDC_CLIENT_ID=hf-ui
HF_UI_OIDC_CLIENT_SECRET=<generated-server-only-secret>
HF_UI_OIDC_REDIRECT_URIS=https://hf.lab.example.ac.kr/oauth/callback
```

For staging without browser OIDC, set in `45-hf-ui.env`:

```bash
HF_UI_ALLOW_STAGING_BYPASS=true
```

Do not use staging bypass in production.

## Authentik OIDC

Re-bootstrap OIDC providers:

```bash
sudo /opt/lab-stack/scripts/22-bootstrap-authentik-oidc.sh
```

Expected:

- `https://auth.lab.example.ac.kr/application/o/hf-ui/.well-known/openid-configuration`
  is reachable.
- Browser login redirects back to `https://hf.lab.example.ac.kr/oauth/callback`.

## Build And Start

```bash
sudo bash -lc '
set -a
. /opt/lab-stack/env/00-global.env
. /opt/lab-stack/env/10-core.env
. /opt/lab-stack/env/20-authentik.env
. /opt/lab-stack/env/35-minio-storage.env
. /opt/lab-stack/env/45-hf-ui.env
set +a
docker compose -f /opt/lab-stack/compose/hf-ui/docker-compose.yml build
docker compose -f /opt/lab-stack/compose/hf-ui/docker-compose.yml up -d
'
```

Reload or recreate Nginx after adding `45-hf-ui.conf` and updating
`nginx.conf`. Since `nginx.conf` is mounted as a single file, recreate the Nginx
container when that file changes:

```bash
sudo bash -lc '
set -a
. /opt/lab-stack/env/00-global.env
set +a
docker compose -f /opt/lab-stack/compose/edge/docker-compose.yml up -d --force-recreate nginx
'
```

## Bootstrap Sample Storage

Create the HF UI MinIO service user, attach `hf-ui-storage-rw`, configure upload
CORS for the model/dataset buckets, and seed one sample model and dataset:

```bash
sudo /opt/lab-stack/scripts/43-bootstrap-hf-ui-storage.sh
```

Expected sample objects:

- `lab-models/demo/tiny-transformer/v1/README.md`
- `lab-models/demo/tiny-transformer/v1/model.safetensors`
- `lab-datasets/demo/sentiment-mini/v1/README.md`
- `lab-datasets/demo/sentiment-mini/v1/train.jsonl`
- `lab-datasets/demo/sentiment-mini/v1/validation.csv`
- `lab-datasets/demo/sentiment-mini/v1/test.json`
- `lab-datasets/demo/sentiment-mini/v1/sample.parquet`

The Parquet sample is generated by `43-bootstrap-hf-ui-storage.sh` using the HF
UI image and `pyarrow`, then uploaded with the existing JSONL, CSV, and JSON
seed files.

The bootstrap also applies CORS for `HF_UI_PUBLIC_URL` to the model and dataset
buckets using `mc cors set`. If a MinIO runtime does not support bucket CORS, the
script falls back to the global `api cors_allow_origin` setting; recreate or
restart MinIO if the subsequent CORS preflight check still fails.

## Browser Smoke

Use a private browser session.

1. Open `https://hf.lab.example.ac.kr`.
2. Confirm sign-in redirects to Authentik.
3. Sign in as a `lab-member`.
4. Confirm model and dataset lists load.
5. Open `demo/tiny-transformer` and confirm README and file tree render.
6. Download `model.safetensors`.
7. Open `demo/sentiment-mini` and select `train`, `validation`, `test`, and
   `sample` preview files.
8. Confirm schema, sample rows, and stats render for JSONL, CSV, JSON, and
   Parquet without layout overlap.
9. Upload a small JSONL file to a new `smoke/` path and confirm progress,
   success state, file-list refresh, and dataset preview.
10. Try the same upload path again with overwrite disabled and confirm the UI
    reports the existing file instead of replacing it.
11. Enable overwrite for the same path and confirm replacement succeeds.
12. Download `train.jsonl`.

## Report And Gate

Record evidence in `/opt/lab-stack/reports/phase5-hf-ui.md`.

Conditional pass requires:

- App builds and starts.
- Container is healthy and publishes no host ports.
- Nginx route returns `/api/health`.
- OIDC discovery exists.
- Staging API flow lists model/dataset entries.
- Model detail, README, file tree, and download URL smoke pass.
- Dataset preview checks pass for JSONL, CSV, JSON, and Parquet. The Parquet
  check expects `sample.parquet` to appear in the dataset file list and preview
  to return rows, schema/source type, and numeric stats.
- Upload checks pass: presigned upload URL uses the public S3 domain, direct PUT
  succeeds, the uploaded object appears in the file tree, JSONL preview can read
  it, duplicate upload without overwrite returns HTTP 409, and CORS preflight
  allows PUT when reachable.

Full pass also requires real DNS/TLS and browser OIDC login evidence.

## Rollback

```bash
sudo docker compose -f /opt/lab-stack/compose/hf-ui/docker-compose.yml down
```

Then remove or disable `45-hf-ui.conf` and recreate/reload Nginx. Preserve:

- `/opt/lab-stack/env/45-hf-ui.env`
- `/opt/lab-stack/hf-ui/catalog/seed.catalog.yaml`
- `/opt/lab-stack/reports/phase5-hf-ui.md`

Do not rotate secrets during rollback unless there is a confirmed exposure.
