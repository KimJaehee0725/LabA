# v0.3 Smoke Runbook

Use `deploy/reports/v0.3-smoke-report.md` as the report template.

Current wave default enabled set:

```bash
ENABLED_SERVICES=core,edge,authentik,gitea,plane,mlflow,nextcloud
```

Overleaf is deferred for this wave and should be reported as deferred, not failed, unless it is explicitly added to `ENABLED_SERVICES`.

Required checks:

- Only `80`, `443`, and optional `2222` are published.
- Core health checks pass.
- Nginx routes respond.
- Authentik groups, MFA, OIDC discovery, and disabled-user block are confirmed.
- Gitea, Plane, MLflow, Nextcloud, and Collabora each complete one write flow.
- MinIO has no anonymous bucket access.
- MLflow unauthenticated access is blocked.
- Backup dry-run reports failures with non-zero exit.

Integrated check:

```bash
sudo ENABLED_SERVICES=core,edge,authentik,gitea,plane,mlflow,nextcloud \
  /srv/lab-platform/scripts/96-check-all.sh
```

MLflow write flow:

- `60-check-mlflow.sh` must create a smoke run.
- The run must exist in Postgres.
- The smoke artifact object must exist in MinIO bucket `mlflow-artifacts`.

Nextcloud/Collabora write flow:

- `72-check-nextcloud.sh` must pass.
- WebDAV upload/download should be run with a runtime-only app password.
- Files, Collectives, Tables, Deck, Calendar, and Collabora entry points should be checked in a browser after Authentik login.
- GitHub integration pass condition is app-enabled/provider-visible only; no GitHub PAT is required.
