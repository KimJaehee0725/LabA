# v0.2 Runtime Gate 1

## Scope

This gate starts only core, edge, and Authentik on the staging server with hosts+self-signed TLS. Do not start Gitea, Plane, MLflow, Nextcloud, Collabora, or Overleaf until this gate passes.

## Prepare Staging Root

```bash
sudo install -d -m 0750 /srv/lab-platform
sudo rsync -a deploy/ /srv/lab-platform/
sudo /srv/lab-platform/scripts/00-create-directories.sh
```

Copy example env files to real env files on the server, then replace placeholders with generated values. Do not record generated values in git, history, or chat.

```bash
sudo cp /srv/lab-platform/env/00-global.env.example /srv/lab-platform/env/00-global.env
sudo cp /srv/lab-platform/env/10-core.env.example /srv/lab-platform/env/10-core.env
sudo cp /srv/lab-platform/env/20-authentik.env.example /srv/lab-platform/env/20-authentik.env
sudo chmod 0640 /srv/lab-platform/env/*.env
```

## Hosts And TLS

Map the staging domains to the staging IP and create the temporary certificate:

```bash
sudo STAGING_IP=<staging-ip> /srv/lab-platform/scripts/06-configure-hosts.sh
sudo /srv/lab-platform/scripts/05-create-self-signed-cert.sh
sudo chmod 0600 /srv/lab-platform/nginx/ssl/origin.key
```

The hosts block includes:

- `auth.lab.snu.ac.kr`
- `hub.lab.snu.ac.kr`
- `lab.snu.ac.kr`
- `mlflow.lab.snu.ac.kr`
- `files.lab.snu.ac.kr`
- `office.lab.snu.ac.kr`
- `papers.lab.snu.ac.kr`
- `storage.lab.snu.ac.kr`

## Start And Check

```bash
sudo /srv/lab-platform/scripts/01-create-networks.sh

docker compose \
  --env-file /srv/lab-platform/env/00-global.env \
  --env-file /srv/lab-platform/env/10-core.env \
  -f /srv/lab-platform/compose/core/docker-compose.yml \
  up -d
sudo /srv/lab-platform/scripts/02-bootstrap-postgres.sh
sudo /srv/lab-platform/scripts/03-bootstrap-minio.sh
sudo /srv/lab-platform/scripts/04-check-core.sh

docker compose \
  --env-file /srv/lab-platform/env/00-global.env \
  -f /srv/lab-platform/compose/edge/docker-compose.yml \
  up -d
sudo /srv/lab-platform/scripts/10-check-edge.sh

docker compose \
  --env-file /srv/lab-platform/env/00-global.env \
  --env-file /srv/lab-platform/env/10-core.env \
  --env-file /srv/lab-platform/env/20-authentik.env \
  -f /srv/lab-platform/compose/authentik/docker-compose.yml \
  up -d
```

Complete the Authentik initial setup, confirm the mounted blueprints are applied, then run:

```bash
sudo /srv/lab-platform/scripts/20-check-authentik.sh
```

## Pass Criteria

- Postgres `pg_isready` succeeds.
- Redis returns `PONG`.
- MinIO health and bucket bootstrap succeed.
- HTTP redirects to HTTPS.
- Authentik initial setup or root page is reachable.
- `lab-admin`, `lab-member`, `lab-collab`, and `lab-guest` exist.
- Only `80` and `443` are externally published.
- `/srv/lab-platform/nginx/ssl/origin.key` is `0600` or stricter.
- Docker socket is not mounted.
