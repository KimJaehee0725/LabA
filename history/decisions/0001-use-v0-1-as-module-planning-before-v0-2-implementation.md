# Decision 0001 - Use v0.1 as module planning before v0.2 implementation

Date: 2026-05-08 10:08 +0000
Status: accepted

## Context

The user wants v0.3 to be the point where the first complete implementation is smoke-tested, and v0.2 to contain module implementation.

## Decision

Define v0.1 as detailed planning, v0.2 as module implementation, and v0.3 as integrated smoke testing.

## Rationale

This gives each service a clear build plan and smoke acceptance criteria before writing operational files for a large security-sensitive platform.
